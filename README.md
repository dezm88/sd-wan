## 自建VPS节点：最省钱，也最费手

自己搭节点的流程不难：买一台目标地区的VPS，用FinalShell这类SSH工具连上去，跑一键脚本把节点建好，再在手机的代理客户端里导入配置。全程几十分钟，服务器月付几十元起步。

难点在IP。服务器默认分给你的是机房IP，拿来做TK要专门挑“双ISP家宽住宅IP”的机器。市面上丽萨主机这类商家有专门的美国4837和9929线路套餐——4837是联通专线，联通宽带用户走这条更快；9929由多家运营商共同运营，电信移动用户也合适——两档最低配分别在60元/月和88元/月上下（以商家当前页面为准）。

这里有个多数教程不会提醒你的坑：**“双ISP”只是IP数据库打的标签，有标签不等于真住宅IP**。一些被大量用户用烂的伪家宽，纯净度可能还不如老老实实标注hosting类型的IP。买之前先去Scamalytics查一下欺诈值，再去ipinfo看IP类型和归属，两关都过了再掏钱。

自建路线的代价是维护全在自己身上：端口配置、防火墙放行、节点掉线排查，都得自己来。认真做直播的人，不建议把账号安全押在自己半吊子的运维能力上。

## 手机环境：网络搭好只完成了一半

一条再干净的线，接到一部脏手机上照样穿帮。按这个清单过一遍：

1. 刷机或恢复出厂设置，清掉旧数据；装过抖音、微信的设备，直播场景建议直接换机
2. 拔掉SIM卡，避免平台通过运营商信息定位你的真实所在地
3. 系统语言、地区、时区全部改成目标市场（做美国区就英语+美区时区）
4. 彻底关闭GPS定位服务
5. 让手机固定连专线发出的Wi-Fi或客户端，别在节点之间来回切
6. 验收：打开TikTok刷For You页，推荐流全是目标语言的本地内容，才算环境过关

## IP到手先“验毒”，三个检查别省

不管是自建还是买的专线，IP先验三样再用：

- **IP类型和归属**：用ipinfo查，看ISP类型是住宅、ISP还是hosting，归属地是否与目标市场一致；手机端也可以直接开ipip.net或whatismyipaddress确认归属地和运营商
- **欺诈值**：Scamalytics的欺诈分数越低越好，0最干净；分数偏高说明这个IP被滥用过，做号风险大
- **DNS落点**：对照目标国家的公共DNS列表，确认解析位置和IP在同一国家——“IP在美国、DNS在中国”这种不一致，是典型的穿帮信号
